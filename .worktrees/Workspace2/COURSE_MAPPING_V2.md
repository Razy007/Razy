# 🗺️ COURSE MAPPING V2 - VISION CIBLE & ÉNERGIE

> Ce document définit la structure officielle des cours pour Pioneer Academy V2.
> Chaque module suit strictement le triptyque : Discovery (Immersion) → Compréhension (Action/Énergie) → Simulation (Maîtrise).

## ⚡ Modèle Énergétique Global
- **Max Énergie** : 100
- **Objectif** : Vider 100 énergie en ~45-60 minutes de jeu intensif (ou 1 module complet + quiz).

| Type d'Action | Coût (⚡) | Rationale |
| :--- | :--- | :--- |
| **Discovery** | 0 | Accroche gratuite. Doit donner envie. |
| **Compréhension (Lab)** | 5 - 10 | Le cœur de l'apprentissage. Analyse, choix simples. |

## 📚 MODULE 1 : PI NETWORK ESSENTIALS (Standard Gold)
**Status:** ✅ IMPLEMENTED (V12)

**Thème** : Comprendre la révolution Pi et son écosystème unique.
**Objectif** : Transformer un "Clicker" en "Pioneer Éduqué".

### 🟢 NIVEAU 1 : LA VISION (L'Origine)
*Accessibilité : Immédiate (Free)*

#### 1. Discovery : "Pourquoi Bitcoin a échoué ?" (⚡ 0)
- **Format** : Storytelling Interactif (Texte + Images évocatrices).
- **Scénario** : 2009, le rêve de Satoshi. 2019, la réalité des fermes de minage centralisées.
- **Hook** : "Vous ne pouvez pas miner du Bitcoin. Mais vous avez un téléphone."

#### 2. Compréhension : "Le Cercle de Confiance" (⚡ 5)
- **Format** : Mini-Lab Interactif.
- **Action** : Vous voyez 5 profils (Mère, Inconnu Twitter, Bot, Ami proche, Echangeur).
- **Mission** : Sélectionnez les 3 seuls valides pour votre Security Circle.
- **Conséquence** : 
    - Erreur : "Votre cercle est faible, piratage simulé." (⚡ Pénalité)
    - Succès : "Taux de minage boosté + sécurité maximale."

### 🔐 NIVEAU 2 : LA VALEUR (Le Mécanisme)
*Condition : Niveau 1 complété*

#### 1. Discovery : "L'Attention est la Monnaie" (⚡ 0)
- **Format** : Dialogue Rapide.
- **Scénario** : Facebook vend votre attention. Pi vous la rémunère.
- **Hook** : "Combien vaut une heure de votre vie numérique ?"

#### 2. Compréhension : "La Rareté du Halving" (⚡ 10)
- **Format** : Graphique Dynamique.
- **Action** : Simulez l'année d'entrée (2019, 2021, 2024).
- **Mission** : Observez la chute du taux de minage.
- **Sim** : Cliquez pour miner à différentes époques. Voyez la différence.
- **Leçon** : "Il est plus dur de gagner du Pi aujourd'hui. L'urgence est réelle."

### 🔐 NIVEAU 3 : L'UTILITÉ (L'Écosystème) - PREMIUM 💎
*Condition : Niveau 2 complété + Premium ou 30 ⚡*

#### 1. Simulation : "Le Marché P2P" (⚡ 20)
- **Format** : Jeu de Rôle Temps Réel.
- **Scénario** : Vous avez 100 Pi. Vous voulez un bien réel.
- **Choix** :
    A. Vendre illégalement contre Fiat (Risque Ban 90%)
    B. Échanger contre un iPhone sur Pi Chain Mall (Stock épuisé)
    C. Échanger contre un service local (Succès moyen)
    D. HODL (Attente Mainnet)
- **Outcome** : Simulez 3 ans de décisions. Voyez votre solde final vs valeur réelle.
