# 🔄 GUIDE UTILISATEUR - FORCER REFRESH PI BROWSER

**Date**: 2026-01-07 22:50  
**Problème**: Pi Browser affiche ancienne version (5 boutons)  
**Solution**: Vider le cache Pi Browser

---

## ✅ MÉTHODE 1 : Clear Cache Android (RECOMMANDÉ)

### Étapes :

1. **Paramètres Android** → **Applications** (ou **Apps**)
2. Cherchez **"Pi Network"** dans la liste
3. Tapez sur **Pi Network**
4. **Stockage et cache** (ou **Stockage**)
5. **Vider le cache** (ne touchez PAS "Effacer les données")
6. Retournez sur **Pi Mining App**
7. Menu → **Pi Browser**
8. Allez sur `pioneeracademy.academy`

**Résultat attendu** : 4 boutons en bas ✅

---

## ✅ MÉTHODE 2 : URL avec Cache Bust (IMMÉDIAT)

### Dans Pi Browser :

Au lieu de taper `pioneeracademy.academy`, tapez :

```
https://www.pioneeracademy.academy/?refresh=20260107
```

Le paramètre `?refresh=` force le rechargement.

---

## ✅ MÉTHODE 3 : Fermeture Forcée (RAPIDE)

1. **Fermez complètement** Pi Mining App (swipe dans Recent Apps)
2. **Ouvrez Paramètres Android** → **Apps** → **Pi Network**
3. **Forcer l'arrêt**
4. **Rouvrez** Pi Mining App
5. **Pi Browser** → `pioneeracademy.academy`

---

## ✅ MÉTHODE 4 : Test Desktop (VALIDATION)

**Sur ordinateur** (Chrome/Firefox/Edge) :

1. Ouvrez `https://www.pioneeracademy.academy/`
2. Appuyez **CTRL + SHIFT + R** (ou **CTRL + F5**)
3. Vérifiez : **4 boutons** en bas ?

**Si desktop = 4 boutons** → Serveur OK, c'est Pi Browser qui cache  
**Si desktop = 5 boutons** → Problème serveur (contactez-moi)

1. Ouvrez mode privé

3. Vérifiez les boutons

## 🔥 MÉTHODE NUCLÉAIRE : Réinstaller App
