## 🔄 MÉCANISME DE RANDOMISATION

Le système utilise `getRandomQuestions()` qui:
1. Récupère toutes les questions du layer
2. Les mélange aléatoirement (`Math.random()`)
3. Sélectionne N questions (configurable)

**Résultat:** Chaque quiz présente une sélection différente, augmentant la durée de vie !
