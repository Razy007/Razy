### 3️⃣ Staking Éducatif (Engagement Long Terme)

**Philosophie** : Récompenser l'engagement durable + utiliser les fonds stackés

#### Fonctionnement

**Utilisateur stake X π pour Y jours** :

- 7 jours → 2% APR
- 30 jours → 5% APR
- 90 jours → 8% APR

**Avantages pour l'app** :

- Liquidité temporaire pour développement
- Utilisateurs "locked in" (rétention)
- Commission discrète (ex: 1% de frais de déblocage anticipé)

**Exemple** :

- User stake 0.1 π pendant 30 jours
- User gagne : 0.1 × 5% / 12 = 0.000416 π/mois
- App retient : 0.1 π temporairement
- **Revenus app** : 0.001 π (frais déblocage anticipé si ≥ 20% des users)

**Revenus projetés** : 0.0005 π/user/mois (conservateur)
